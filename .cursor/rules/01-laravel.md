# Laravel Development Rules

- Use Laravel 12.x features and conventions.
- Follow PSR-12 coding standards.
- Format all code with Laravel Pint.
- Keep controllers focused on HTTP requests and responses.
- Use Form Requests for validation.
- Use Route Model Binding whenever possible.
- Use Eloquent relationships instead of manual joins where appropriate.
- Use dependency injection instead of creating objects manually.
- Prefer named routes.
- Write readable and maintainable code.
- Avoid duplicate logic.
